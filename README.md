# Study Repository

A comprehensive study path covering programming languages, web technologies, and computer science fundamentals. This repository contains notes, code examples, and projects from various learning resources and courses.

## 📚 Repository Structure

### Programming Languages

#### **C**
- **CS50 Course**: Problem sets and implementations covering memory, data structures, and algorithms
  - Assignments: `brick`, `caesar`, `change`, `readability`, `plurality`, `runoff`, `scrabble`
  - Advanced topics: `filter`, `inheritance`, `recover`, `sort`, `speller`, `volume`
- **W3School**: Core C fundamentals

#### **JavaScript**
- **Doka**: Advanced JavaScript concepts
- **Jest Docs**: Testing and unit testing patterns
- **MDN**: Core language features and extensions
- **YouTube**: Learning from James Q and other creators

#### **Python**
- **CS50 Course**: Python fundamentals and problem solving
- **Metanit**: Comprehensive coverage of data types, functions, OOP, modules, etc.
- **Self-Study**: OOP and recursion implementations
- **MS Copilot**: Encryption and security topics

#### **Solidity**
- **Official Docs**: Smart contract development fundamentals
- **Syfrin Updraft**: Practical projects (FundMe, SimpleStorage)
- **GitHub Copilot**: Example implementations
- **NatSpec**: Documentation standards for smart contracts

#### **SQL**
- **CS50 Course**: Database design (`fiftyville`, `movies`, `songs` projects)
- **Metanit**: Database operations and advanced queries
- **W3School**: SQL fundamentals

#### **TypeScript**
- **Official Docs**: Functions, narrowing, and type system features
- **YouTube**: Video tutorials and practical examples

### Technologies

#### **CLI**
- Command-line interface concepts and tools

#### **Git**

#### **Web**

#### **Web-3**

## 🎯 Study Path

1. **Fundamentals**: C, Python basics, core computer science concepts
2. **Web Development**: JavaScript, TypeScript, HTML/CSS
3. **Databases**: SQL for data modeling and queries
4. **Web Technologies**: Git, CLI tools, web architecture
5. **Advanced Topics**: Smart contracts (Solidity), Web-3, design patterns
6. **Theory**: Apply learned concepts to understand software design principles
